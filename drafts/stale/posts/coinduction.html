A Simple Introduction to Coinduction

04/15/2025


Most of the intended audience of this post are likely familiar with induction. This same likely cannot be said about coinduction, the dual of induction. My aim is to introduce coinduction in a self-contained manner, with a focus on intuition. Then, at the end, apply coinductive reasoning to think about the correctness of an algorithm to check if a type is a subtype of another.

Monotone Functions and Fix Points
Fix some universal set $\mathcal{U}$. We are going to study "monotone" functions from $\mathcal{P}(\mathcal{U})$ to itself, where we define a function $F$ as monotone if for some $X, Y \in \mathcal{P}(\mathcal{U}), X \subseteq Y$, then $F(X) \subseteq F(Y)$. Here, we're going to think of $\mathcal{U}$ as a universe set, containing all the objects we can build. We can then think of a monotone function $F$ as a way to specify rules: given a subset $Q \subseteq \mathcal{U}$, $F(Q)$ represents the maximum amount of things we can build with the items in $Q$. We categorize subsets, $Q$, in relation to a function $F$ in 3 different ways: $F$-closed means $F(Q) \subseteq Q$, $F$-consistent means $Q \subseteq F(Q)$, and fixed point if $F(Q) = Q$. We have two fixed points in our example: $\{A\}$ is the smallest and $\{A, B, C\}$ is the biggest. We're going to make these fixed points objects of interest for the rest of this post.
